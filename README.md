# 📷 Portfolio Fotografico

Portfolio fotografico personale realizzato per **Nico Bonanno**, con l'obiettivo di presentare e valorizzare i suoi lavori fotografici

Il sito è stato sviluppato con **Astro**, utilizzando HTML, CSS e JavaScript/TypeScript.

---

## ✨ Funzionalità

* 📸 Portfolio fotografico
* 🖼️ Gallerie organizzate per categorie
* ↔️ Visualizzazione orizzontale delle fotografie
* 🔲 Visualizzazione a griglia
* 🔍 Lightbox a schermo intero
* 👆 Navigazione tramite swipe su dispositivi mobili
* 📱 Layout completamente responsive
* 🌐 Supporto per italiano e inglese
* 🎨 Interfaccia minimale e orientata alla fotografia
* 🚫 Protezione dal click destro sulle immagini

---

## 🖼️ Galleria

Le fotografie sono suddivise in diverse categorie per permettere una navigazione più ordinata del portfolio.

La galleria dispone di due modalità di visualizzazione.

### ↔️ Visualizzazione orizzontale

È la modalità predefinita.

Le fotografie vengono visualizzate orizzontalmente mantenendo le loro proporzioni originali.

### 🔲 Visualizzazione a griglia

La modalità a griglia organizza automaticamente le fotografie in righe mantenendo le proporzioni originali delle immagini.

Le dimensioni vengono calcolate dinamicamente in base alla larghezza disponibile, permettendo di ottenere una galleria di tipo **justified gallery**.

---

## 🔍 Lightbox

Cliccando su una fotografia viene aperta una visualizzazione a schermo intero.

### Desktop

* ⬅️ Fotografia precedente
* ➡️ Fotografia successiva
* ✕ Chiusura del lightbox
* ⌨️ Navigazione tramite tastiera
* ♾️ Navigazione circolare tra le fotografie

### Mobile

* 👆 Navigazione tramite swipe
* 📱 Visualizzazione a schermo intero
* ♾️ Navigazione circolare tra le fotografie

---

## ⏳ Caricamento delle immagini

Per migliorare le prestazioni del sito, le fotografie vengono caricate utilizzando il **lazy loading** quando appropriato.

Una volta completato il caricamento, la fotografia appare gradualmente tramite una breve animazione di dissolvenza.

Il comportamento del caricamento è adattato sia alla visualizzazione desktop che a quella mobile.
